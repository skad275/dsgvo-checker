🛡️ DSGVO Tool-Checker für Schulen

Analysiere Datenschutzerklärungen von KI-Tools direkt im Browser.

👉 Hier klicken: Anleitung & kostenlosen API-Schlüssel auf Google AI Studio erstellen
ℹ️ Kurzanleitung zur Schlüsselerstellung anzeigen
  1. Öffne aistudio.google.com und melde dich mit deinem Google-Konto an.
  2. Klicke auf "Get API key" und danach auf "Create API key in new project".
  3. Kopiere den erzeugten Schlüssel (beginnt mit AIzaSy...) und füge ihn oben ein.
📋 Vorgehensweise:
1. Suche auf der Website des gewünschten Tools ganz unten im Fußbereich (Footer) nach der Datenschutzerklärung.
2. Achte bei englischsprachigen Tools auf Begriffe wie Privacy Policy, Privacy Statement, Terms of Service (ToS) oder Data Processing Addendum (DPA).
3. Markiere den gesamten Text auf der Seite, kopiere ihn (Strg + C) und füge ihn unten in das Feld ein (Strg + V).
